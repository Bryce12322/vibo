# Vibo

**打开看板，知道 AI 编程项目做到哪、还差什么、有什么需要你处理。**

[English](README.md) · [安装指南](INSTALL.md) · [本地体验版 0.9.2](https://github.com/Bryce12322/vibo/releases/tag/v0.9.2)

## 在项目里说一句

> 请按照 https://github.com/Bryce12322/vibo 的安装指南，为当前工具安装 Vibo 本地版，读取持续汇报规则，跟踪当前项目并同步已有计划，优先在内置浏览器打开看板，后续开发主动更新实际进展。已有线上关联请先识别并保留。

默认使用 **Skill＋CLI**，进展保存在本机。首次使用无需配置 MCP 连接器、OAuth 或账号。宿主命令执行权限按提示确认。

Agent 安装完整包，从当前上下文整理交付目标和关键事项，一次保存并打开看板。继续正常开发时，按已加载规则更新计划、实现、检查和需要你处理的事项。下次继续同一项目时恢复原 ID 和记录。

## 适用范围

- macOS，需要 Node.js 22.13+。WorkBuddy 自带合适版本时可复用。
- Codex 安装入口与本地 CLI 闭环已验证。
- WorkBuddy 5.11.3 已在已安装技能列表实际发现并启用 track-project。CLI 闭环已验证，多轮开发、跨对话自动上报和内置开页仍待完整宿主验收。
- Windows、Linux 和其他宿主尚未完成安装验收。
- 0.9.2 通过 59 项自动测试，覆盖安装升级、多项目隔离、批量保存、重试去重、失败回滚、检查、备份和恢复。

看板按交付目标组织功能开发、部署、域名与支付等事项。待推进工作靠前，已实现项折叠。实现、检查证据、人工验收分别记录。

首次先让当前计划可见，历史导入按需进行。持续自动上报依赖宿主加载规则并实际调用。

本地服务仅监听 127.0.0.1。兼容保留 track-project 技能名与 ~/Library/Application Support/Qingzhou/ 数据目录。升级备份旧 Skill，安装器尚未做 Apple 签名或公证。

## 按需使用线上版

[线上看板](https://vibo.bryceyufeng.workers.dev)继续可用，需要线上使用时按 [线上接入说明](CONNECT.md#online)配置。已有线上关联继续保留。本地与云端没有自动双向同步，迁移需要明确选择并核对记录。

WorkBuddy 线上 OAuth 注册回调兼容问题仍待修复，首次体验请用本地入口。

[提交反馈](https://github.com/Bryce12322/vibo/issues)，附工具、系统、Vibo 版本和可见错误，勿附凭据、私有数据库或完整对话。

本仓库提供分发说明，完整运行文件在 Release 安装包内。
