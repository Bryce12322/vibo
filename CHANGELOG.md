# Release notes / 更新记录

## 0.9.1 — Local preview / 本地体验版

- Local multi-project dashboard with delivery goals, remaining work, check evidence and explicit requests for user input.
- Codex skill with fixed reporting fields, activity heartbeats, conflict detection and retry support.
- English and Simplified Chinese UI; project records retain their original language.
- Refined neutral interface with blue actions, compact summaries and folded implemented work.
- Local SQLite storage, backup/recovery commands, and an installer that preserves records on update.

Requires macOS, Codex and Node.js 22.13+. No cloud service or Vibo account required. The installer is unsigned. Progress depends on agent reports; source-code scanning and guaranteed background tracking are not included.

按交付目标查看剩余工作、检查证据及明确需要用户处理的事项；支持多项目、中英文界面、本地备份恢复和保留记录的更新。安装包未签名，依赖 Agent 主动上报。
